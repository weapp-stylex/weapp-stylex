<Tab label="styles.ts">

```ts
import * as stylex from 'weapp-stylex'

export const styles = stylex.create({
  card: {
    padding: 16,
    marginTop: '12rpx',
    borderRadius: 12,
    backgroundColor: '#edf7f1',
  },
})
```

<Tab label="Native">

```ts
import * as stylex from 'weapp-stylex'
import { styles } from './styles'

Page({
  data: { card: stylex.attrs(styles.card) },
})
```

```xml
<view class="{{card.class}}" style="{{card.style}}">
  StyleX
</view>
```

</Tab>

<Tab label="Wevu">

```vue
<script setup lang="ts">
import * as stylex from 'weapp-stylex'
import { computed } from 'wevu'
import { styles } from './styles'
const card = computed(() => stylex.attrs(styles.card))
</script>

<template>
  <view :class="card.class" :style="card.style">StyleX</view>
</template>
```

</Tab>

<Tab label="Taro React">

```tsx
}
```

## From style modules to native WXSS

<div className="home-flow">

<Steps>

<Step title="Define styles">

Use create(), tokens and themes in ordinary TS / JS modules.

</Step>

<Step title="Bind to views">

Connect attrs() class/style or React props() to framework updates.

</Step>

<Step title="Build for WeChat">

The compiler collects and deduplicates rules; adapters connect page and component WXSS.

</Step>

</Steps>

</div>

Numeric `16` stays `16px`; write `'16rpx'` for mini-program relative units. Styles are generated at build time without runtime stylesheet injection.
