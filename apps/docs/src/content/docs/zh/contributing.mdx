## Workspace 工作流

私有仓库与文档站使用 repoctl `5.10.3`、pnpm `12.11.2` 与 Node.js `^22.22.3 || ^24.16.0 || >=26.3.0`，CI 使用 Node 22.23.3 和 24.21.0。发布库继续保持 `^22.22.1 || >=24.11.0`，独立 ESM/CJS 消费者在 Node 22.22.1、24.11.0 上检查。通过 `corepack pnpm exec repo new <name> --template <key>` 创建包，保持适配器精简，共享编译行为放在 `@weapp-stylex/compiler`。

六个发布库统一使用 tsdown `0.23.1`：core 与 weapp-vite 保留 ESM-only，其余四包保留 ESM/CJS，所有代码入口均提供声明文件。TypeScript 保持 `6.0.3`：TypeScript 7 移除了根入口的旧 Compiler API，repoctl、Astro check 与 TypeScript ESLint 也尚不支持该主版本。共享 StyleX 编译器保留 Babel 7，各框架工具链单独解析。升级决策和验证状态见 [2026-10-15 依赖记录](https://github.com/weapp-stylex/weapp-stylex/blob/main/docs/dependency-upgrade-2026-10-15.md)。

编译器改动提交前执行完整[验证流程](/zh/examples/)。可发布包的变更使用 `corepack pnpm change`，文档改动不会发布 npm 包。

## 文档源码

[stylex.weapp.dev](https://stylex.weapp.dev/) 起始于 repoctl Nimbus 模板，使用 Nimbus `0.18.1` 和 Astro `7.3.8`，布局与组件由项目维护。内容位于 `apps/docs/src/content/docs/`：英文使用根相对路径，中文放在 `zh/` 下的对应文件；教程与 API 参考使用各自子目录。

```sh
corepack pnpm --filter docs dev
corepack pnpm --filter docs lint
corepack pnpm --filter docs typecheck
corepack pnpm --filter docs build
corepack pnpm --filter docs check:site
corepack pnpm exec node scripts/test-docs-browser.mjs
corepack pnpm --filter docs test
corepack pnpm --filter docs preview
```

生产构建生成 Pagefind 搜索。`scripts/test-docs-browser.mjs` 在独立文档工作流中 headless 检查双语搜索、快捷键与焦点、代码复制、主题持久化、语言切换、移动导航和无 JavaScript 内容，并关闭自己创建的浏览器与服务。开发服务器不提供完整搜索索引。

发布新页面前补齐两个语言版本，保持代码行为与公开链接一致。注册传达信息的 MDX 组件时，同时提供 Markdown 文本转换；除了视觉页面，还需检查自定义 tabs/steps 在 Markdown 导出中的内容。[实践教程](/zh/recipes/)应展示真实框架绑定，[API 参考](/zh/api/)应与包导出及源码类型一致。

验收记录保留日期。[2026-10-09 运行记录](https://github.com/weapp-stylex/weapp-stylex/blob/main/docs/ide-validation-2026-10-09.md)区分各产物分别通过与完整 suite 仍待验收，后续文档编辑不能将历史结果改写成没有证据的当前验收成功。

## 工具读取入口

每页提供 `/index.md` 和 `/index.mdx`。`/llms.txt` 列出文档，`/zh/llms.txt` 列出中文页面，`/llms-full.txt` 包含完整公开文本。它们与网站使用同一内容源生成。

## 部署

Cloudflare Workers Static Assets 托管静态 `dist/`。`apps/docs/wrangler.jsonc` 管理 `stylex.weapp.dev` custom domain，DNS 与 TLS 自动配置。canonical 与语言 alternate 链接统一使用这个主域名。

```sh
corepack pnpm --filter docs deploy:dry-run
corepack pnpm --filter docs deploy
```

本地先完成 Wrangler 认证，不要提交凭据。验证与回滚参见[部署手册](https://github.com/weapp-stylex/weapp-stylex/blob/main/docs/site-deployment.md)。
