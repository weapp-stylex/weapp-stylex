## 定义一次，组合使用

保留官方 StyleX API。把样式写进普通模块，用 `attrs()` 或 `props()` 组合，再编译成微信小程序的原子 WXSS。

[快速开始 →](/zh/get-started/) · [查看示例](/zh/examples/) · [GitHub](https://github.com/weapp-stylex/weapp-stylex)

```ts
// styles.ts
import * as stylex from 'weapp-stylex'

export const styles = stylex.create({
  root: { padding: 16, marginTop: '12rpx', backgroundColor: 'white' },
  active: { opacity: 0.6 },
  meter: (width: number) => ({ width, height: 12 }),
})
export default styles
```

## 熟悉的语义，原生产物

共享模块支持具名导出、默认导出、barrel、路径别名和 workspace 源码。主题沿用官方 token，动态值交给官方 runtime。数值 `16` 保持 `16px`，需要时显式写 `'16rpx'`。

无需 CSS Layers 或运行时样式注入。构建适配器收集、去重规则，输出 `stylex.wxss`，再接入页面与组件样式。

当前支持微信主包和普通分包。接入独立分包或其他平台之前，请先查看[支持边界](/zh/faq/)。
