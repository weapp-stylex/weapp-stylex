对应独立包为 `@weapp-stylex/core`、`@weapp-stylex/weapp-vite`、`@weapp-stylex/taro`（含 `/loader`）、`@weapp-stylex/uni-app` 与 `@weapp-stylex/compiler`，符号与聚合包对应入口相同。聚合包所有代码入口提供 ESM/CJS 与声明文件；独立 core 和 weapp-vite 入口为 ESM。

<a id="api-package-json"></a>
## 包元数据

`weapp-stylex/package.json` 是公开的 JSON 元数据入口，字段描述发布包，不是 runtime 或编译函数。请使用当前 Node/bundler 支持的 JSON 导入语法。构建工具通过显式子路径导入，根 runtime 入口不会引入构建工具。

## 理解微信边界

<Aside type="warning" title="公开导出不代表微信端已验证">

项目保留官方 StyleX 语义与 TypeScript 声明。属性通过类型检查，或官方 helper 出现在这里，都不能证明 WXSS 与特定微信基础库支持它。浏览器高级 API 和 unstable 导出在对应条目中单独说明边界。

</Aside>

稳定目标为微信原生 Page/Component、Wevu、Taro React/Vue 3 的 Vite 与 Webpack 5 构建，以及 uni-app Vue 3。支持普通分包；独立分包、其他小程序平台、Vue 2、uni-app x、自定义 WXML `sx` 语法与 stateful HMR 不在稳定契约内。各宿主的验收证据见[示例与验收](/zh/examples/)。

## 阅读约定

签名依据已安装公开声明；较长的官方泛型约束会明确使用简写，最终以类型推断为准。数值长度遵循 StyleX：`16` 表示 `16px`，`rpx` 请写成 `'16rpx'`。编译期 helper 需要适配器；运行时通过 `attrs()` 或 `props()` 组合已转换的样式。

官方函数导出还提供同名 `typeof` 类型别名，例如 `import type { create } from 'weapp-stylex'`，每个别名随函数说明。`attrs` 与 `props` 是函数声明，没有同名别名。声明使用的内部类型不自动成为顶层公开导出。
