## Install and configure

```sh
pnpm add weapp-stylex
```

```ts
// config/index.ts
import { defineConfig } from '@tarojs/cli'

export default defineConfig({
  projectName: 'my-stylex-app',
  sourceRoot: 'src',
  outputRoot: 'dist',
  framework: 'react',
  compiler: { type: 'vite' }, // or webpack5
  plugins: [require.resolve('weapp-stylex/taro')],
})
```

Set `compiler.type` to `webpack5` to use Webpack. The plugin selects the builder through public Taro hooks; no manual loader registration is required. To pass options, use `plugins: [[require.resolve('weapp-stylex/taro'), { importSources: ['weapp-stylex', '@weapp-stylex/core', '@stylexjs/stylex'] }]]`.

## Compose shared styles

Create a shared module using the [styles guide](/styles/), then bind its result:

```tsx
import { useState } from 'react'
import { View } from '@tarojs/components'
import * as stylex from 'weapp-stylex'
import { styles } from './styles'

export default function Card() {
  const [active, setActive] = useState(false)
  return (
    <View
      {...stylex.props(styles.root, active && styles.active)}
      onClick={() => setActive(!active)}
    >
      <View {...stylex.props(styles.meter(80))}>Shared styles</View>
    </View>
  )
}
```

`props()` returns React-compatible className and style props. Spread them onto Taro View.

## Builder versions and units

The examples verify Taro `4.3.0`, React `18` / Vue `3`, Vite `4` and Webpack `5.91.0`. Keep all `@tarojs/*` packages on the same version. Avoid global Vite or Babel overrides that replace Taro's toolchain.

StyleX WXSS is emitted after Taro's dimension transforms. Numeric `16` remains `16px`; use `'16rpx'` explicitly. Webpack stores StyleX metadata in module `buildInfo` so filesystem cache hits still contribute CSS.

The [taro-react example](https://github.com/weapp-stylex/weapp-stylex/tree/main/examples/taro-react) builds two separate artifacts sequentially, with shared styles, multiple consumers, theme switching, dynamic values and ordinary subpackages.
