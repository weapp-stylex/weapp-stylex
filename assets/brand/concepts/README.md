# weapp-stylex logo 候选

五个候选均提供可编辑 SVG、1024px 透明 PNG 和独立的深浅底预览。

- A：双轨环抱，完整小程序圆标 + StyleX 官方轨道。
- B：负形合印，将两种图形收拢进单色圆章。
- C：曲线交织，去掉小程序外圆，内部曲线与官方 X 交织。
- D：叠合徽章，保留原标，用 StyleX 表示适配关系。
- E：几何双环，参考官方轨道重绘为等宽椭圆。

打开 index.html 可切换深浅背景、查看 32–160px 图标并下载文件。comparison.png 为静态总览。

素材来源：

- 用户提供的 `Vector.svg`：保存于 [sources/wechat-miniprogram.svg](sources/wechat-miniprogram.svg)。
- StyleX 官方 favicon：https://stylexjs.com/favicon.svg（2026-10-09 核对）。
- StyleX 官网：https://stylexjs.com/。

当前采用 A「双轨环抱」作为 weapp-stylex 标识，其余方案保留供后续设计参考。A–D 使用官方原始路径；E 为轨道重绘。
